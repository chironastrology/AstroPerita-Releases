# AstroPerita Releases

Official desktop releases of AstroPerita by CHIRON Astrology.

AstroPerita is proprietary software. Source code is not distributed through this repository.

Official product information, documentation and support:

https://www.chiron-astrology.com/astroperita

## Downloads

The latest stable version of AstroPerita is available from the Releases section of this repository.

### macOS

Supported systems:

* macOS 12 Monterey through macOS 26 Tahoe
* Apple Silicon
* Intel x86_64

A current macOS version is recommended.

### Windows

Supported systems:

* Windows 10, 64-bit
* Windows 11, 64-bit
* Intel/AMD x64

Windows 11 is recommended.
